# Data directory

Raw third-party datasets are **not redistributed** in this repository. Download
them from the original providers and place them here before running
`notebooks/01_data_loading.ipynb`.

| File | Source |
|---|---|
| `german.data` | UCI ML Repository, Statlog German Credit (dataset 144). Notebook 01 fetches it automatically if missing. |
| `default of credit card clients.xls` | UCI ML Repository, Default of Credit Card Clients (dataset 350). Notebook 01 fetches it automatically if missing. |
| `application_record.csv`, `credit_record.csv` | Kaggle "Credit Card Approval Prediction". Must be placed here manually. |

`processed/` is regenerated by notebooks 01–02 and is safe to delete.
